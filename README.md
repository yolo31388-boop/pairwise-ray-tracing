# 游戏内光线追踪与路径追踪系统

## 项目描述

游戏内光线追踪与路径追踪系统的bug修复项目。核心模块 `rendering/ray_tracing.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 光线追踪完全没做阴影都是硬边
- 路径追踪完全没做只能做简单的光线投射
- 全局光照完全没做不能计算间接光照
- 反射折射完全没做水面没有反射
- 焦散完全没做水面下没有焦散

## 运行测试

```bash
python -m pytest tests/test_ray_tracing.py -q
```

修复目标：所有 16 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
